# 🍎 FreshCheck

An AI-powered fruit freshness detection project that uses image classification to identify whether fruits are fresh or rotten.

### ✨ Features
- AI-based image classification
- Supports apples, bananas, and oranges
- Simple and user-friendly interface
- Instant freshness predictions

### 🛠️ Built With
- Python
- TensorFlow / MobileNetV2
- TensorFlow Lite
- HTML, CSS & JavaScript

### ⚠️ Disclaimer
FreshCheck provides visual estimates only. It is an educational AI project, not a food-safety testing tool.
